# Kit de identidade do Ierri

Kit pronto para integrar ao site (incluindo shadcn/ui), com logos em SVG/PNG, favicon, ícones, avatar, capa de compartilhamento e documentação. Sem fontes binárias, código de aplicação ou variáveis CSS customizadas.

## Pastas

- `logos/svg/`: logotipo vetorial sem texto, em oito versões.
- `logos/png/`: exportações em PNG (transparência ou fundo indicado).
- `icons/`: favicon SVG/ICO, PNG 16/32/48, apple-touch-icon, ícones Android e `site.webmanifest`.
- `social/`: avatars quadrados e capa Open Graph.
- `docs/GUIA-DA-MARCA.md`: paleta HEX, tipografia, posicionamento, UI e aplicação.
- `docs/INSTRUCOES-PARA-CODEX.md`: instruções de integração no repositório existente.
- `previews/`: visualização e referência de identidade.

## Arquivos para começar

1. Logo do header: `logos/svg/ierri-symbol-primary.svg`
2. Favicon: `icons/favicon.ico` ou `icons/favicon.svg`
3. App icon: `icons/apple-touch-icon.png` e `icons/android-chrome-*.png`
4. Avatar GitHub: `social/github-avatar-512.png`
5. OG image: `social/open-graph-1200x630.png`
6. Guia de cores e fontes: `docs/GUIA-DA-MARCA.md`

**Coral:** `#FF4D3D`; **grafite:** `#171717`; **off-white:** `#FAF9F6`; **branco:** `#FFFFFF`.  
**Fontes:** Space Grotesk (títulos) + Inter (UI) - veja URLs no guia.
